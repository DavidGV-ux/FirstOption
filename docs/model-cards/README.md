# Model cards

Aún no hay modelos implementados; por tanto, no hay model cards
válidas. Se crearán con el Incremento 5 (pronóstico de referencia) y
solo contendrán lo verificable: objetivo, uso previsto, usos
excluidos, población, datos, variables, método, horizonte,
incertidumbre, métricas, validación, limitaciones, estado de
aprobación y versión.

**Compromiso:** ninguna model card afirmará validación clínica ni
aprobaciones que no existan. TRIPOD+AI se usará como guía de
transparencia, no como certificación.
